# User Guide - Sprint 2 Update

## Getting Started
Welcome to the latest version of HardwareShopPro! This guide covers the new features released in Sprint 2.

### 1. Dashboard
- View key metrics like Total Sales, Low Stock Alerts, and Revenue.
- Click on "Low Stock" cards to quickly navigate to Inventory.

### 2. Billing / POS
- **Navigate**: Click "Billing" in the sidebar or press `F2`.
- **Search**: Type product name or scan barcode.
- **Add to Cart**: Click product card. Use + / - to adjust quantity.
- **Customer**: Select existing customer or leave as "Walk-in".
- **Checkout**: Press `F9` or click "Generate Invoice". Confirmation will appear.
- **Payment**: Select Cash, Card, or UPI. Cash automatically calculates change.

### 3. Reports
- **Navigate**: Click "Reports" in the sidebar.
- **Date Range**: Use the date pickers or quick buttons (Today, Week, Month).
- **Charts**: Interactive bar chart for revenue and pie chart for top products.
- **List**: Scroll down to see full invoice history. Click "View Details" (eye icon) for line items.

### 4. Settings
- **User Management**: Add new cashiers/managers. Only Admins can modify users.
- **Business Profile**: Update store name, address, and logo for invoices.
- **Appearance**: Toggle Dark Mode and Accent Color.
- **AI Config**: Enter your API Key to enable the Smart Assistant.
- **Backup**: Create manual backups of your database.

### 5. AI Assistant
- **Navigate**: Click "AI Assistant" in the sidebar.
- **Usage**: Type natural language questions.
- **Examples**:
  - "Show me all screwdrivers" -> Searches inventory.
  - "Sales for last month" -> Generates report summary.
  - "Low stock items?" -> Lists products needing reorder.

## Troubleshooting
- **No data in reports?** Ensure the date range covers your transactions.
- **Can't generate invoice?** Check if cart items exceed available stock.
- **AI not responding?** Verify internet connection and API Key in Settings.
